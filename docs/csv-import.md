# Reviewed pasted CSV import

The table workspace offers Import CSV for disposable SQLite. It accepts pasted text, not file access: at most 64 KiB UTF-8, 100 data rows, 16 columns, and 2048 characters per cell. Headers cover every actual column. Quoted commas, escaped quotes and multiline fields are parsed; unknown or duplicate headers, malformed quoting, unsupported values and oversized inputs fail atomically. Unquoted `\N` is NULL; empty fields remain empty text and quoted `"\N"` remains text. Numerical columns use finite JavaScript numbers, not arbitrary-precision decimals.

Only simple known tables with complete metadata qualify. BLOB, triggers, virtual tables, defaults/generated definitions and ON CONFLICT definitions are refused. Every cell is a parameter to one generated INSERT statement, not SQL syntax. Preview executes nothing. The handle-bound exact issued review is consumed once, shares the latest-review slot with schema/grid changes, and checks the schema revision again. All rows run in one savepoint; duplicate keys, foreign key violations or budgets roll back the entire batch. Successful imports clear old results without running a query.

Nine model tests, five actual SQL.js engine tests and eight controller tests pass. The main SDK/remote-DOM regression verifies two-row import, explicit readback and full rollback after a duplicate in a later row. Those transports are injected, not native app evidence. Alpha.18 is installed in the full Netcatty app, but native CSV submission/readback is still pending as UI review work took priority. Do not report this as remote-service or multi-database qualification.
