# SQL editor parity and public host boundaries

Read-only reference inspection: DBX checkout b6c3d47; Netcatty main host checkout
`database-host-main`. These are source observations, not native acceptance evidence.

## Actual DBX implementation

DBX uses **CodeMirror**, not Monaco:
`apps/desktop/src/components/editor/queryEditorCodeMirrorRuntime.ts:273–280,395–402`.
`QueryEditor.vue:1911–1924` formats a selection if present, otherwise the entire
file. Lines 1964–1980 reject stale asynchronous formatting results and map the
selection through the edit. The dialect-aware formatter lives in
`lib/sql/sqlFormatter.ts`; this plugin does not claim to reproduce it fully.

`useQueryEditorCompletion.ts:871–918` uses the actual document/caret, connection,
dialect and semantic analysis; it declines during composition and cancels stale
results on document change. `useQueryEditorExecution.ts:45–93` captures manual
selection before toolbar focus changes and gives selection execution priority;
otherwise execution resolves the configured cursor-statement/all-document target.
`QueryEditor.vue:3201–3210` guards execution against IME and repeated key events.

## Current plugin and main API

`src/SqlEditor.tsx` is a host textarea with display-only highlighting and line
numbers. It is not an embedded CodeMirror or Monaco instance.

Main `components/plugins/PluginRemoteSurface.tsx:98–111` sends value, key/modifier
flags and composition event data, but **not selectionStart/selectionEnd, select
notifications, isComposing, keyCode or repeat**. The same limitation is explicit in
`packages/plugin-contract/src/generated/plugin-contract.ts:210–225`.
`packages/plugin-sdk/src/hostDom.ts:37–40` reconstructs keyboard/composition events;
it cannot recover the real host selection. Reading the sandbox textarea selection
would therefore not read the user's actual caret. Async event dispatch also does
not make sandbox preventDefault a synchronous host keyboard cancellation API.

Consequences: real caret completion, selection formatting/execution, robust Tab/
Enter completion acceptance and exact selection restoration need a public host
contract extension. Do not emulate them through private events or present a fake
editor as native Monaco. Composition events can gate explicit plugin actions, but
are not complete parity with DBX's IME execution guards.

## First independently testable slice

`sqlFormat.ts` offers conservative full-document SQLite **whitespace-only**
formatting. It preserves every token's spelling/order and every quoted string,
identifier, bound parameter and comment; line comments retain their exact original
LF terminator (including a preceding CR in CRLF), or EOF. Bare CR is opaque
comment content, not a SQLite line-comment terminator; formatting must never expose
the SQL-looking text after it. A second lexical pass verifies the invariant. It does not parse
or validate SQL, execute SQL, or provide selected-text/caret operations. Autogenerated
SQLite expression column labels can change when expression whitespace changes;
explicit aliases and result values are unaffected in the real-engine tests.

The scanner refuses unknown lexical characters, unclosed quotes/comments or
parentheses, nested block comments, unsupported dollar-quote forms, numeric
separators, procedural bodies and PRAGMA. Limits are 8192 UTF-16 units and UTF-8
bytes, 2048 tokens, and 64 parenthesis levels. Scanning/printing is linear in these
bounded inputs; this is not a worker-level execution timeout or a full SQL parser.

There is **no UI integration yet**. A future explicit Format/Apply/Undo flow must
invalidate pending drafts on any document, tab, connection or schema transition;
never run formatted SQL automatically. Do not reuse the display-only highlighter
as a rewriting lexer: its incomplete-token tolerance and segment-budget fallback
are appropriate for drawing, not editing.

Schema-aware help can use the already-loaded schema with bounded searchable table/
view/column candidates and correctly quoted identifiers. Without the public caret
contract, label insertion explicitly as **append at end** or **copy identifier**,
not automatic cursor completion. No additional network metadata fetch is needed.
